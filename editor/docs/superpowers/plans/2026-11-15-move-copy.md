# Move and Copy/Paste Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drag elements with the Select tool and copy/paste them with Ctrl+C / Ctrl+V, for elements drawn this session and for host (Revit) elements, with host moves and copies executed in Revit.

**Architecture:** Drawn elements change through S1's one-undo-step `replaceElements`, extended to carry ink (strokes). Host elements get two new frozen-contract ops, `move` and `copy` (decision 0012), sent under the existing streaming rules (M6-12); the add-in maps them through the plan viewport under the grab point to model vectors and runs `ElementTransformUtils.MoveElements` / `CopyElements`, recording what it needs to revert.

**Tech Stack:** TypeScript / React / Vitest (`editor/`, run with `npx -y pnpm@12.4.1 …`); C# .NET (`revit/`, `dotnet`), Revit 2026 API.

**Spec:** `editor/docs/superpowers/specs/2026-11-15-move-copy-design.md`

## Global Constraints

- Editor done = `pnpm check` green; add-in done = `dotnet build` + `dotnet test` green (`Protocol_mismatch_is_refused` fails on Windows on `main` too; excluded). `pnpm e2e` cannot launch Chromium here (`spawn EPERM`): say so, never claim it.
- `src/core/types` changes only with decision 0012 and every consumer updated (AGENTS.md rule 5). No new dependencies. Tests cite `S2-0x` (task file `editor/docs/tasks/S2-move-copy.md`).
- Spec values: drag starts past a threshold (builder: 4 screen px); pasted host door snaps to a wall within **1 m**; one `move` per host element (`strokeId: "move:<elementId>"`); copies `strokeId: "copy:<n>"`; joined walls follow; copies onto another level take the target level; copying a wall copies its hosted doors/windows; drawn pastes keep real-world size.
- Only sheets with plan viewports take host moves/copies; plain PDFs and view pages do not.
- Live Revit runs touch only elements the run creates, deleted at the end; never sync with central.

## Review Focus

1. A click (press + release within the threshold) on an element selects it and never moves it. → Task 7 `dragOffset` test.
2. Dragging a host door: it slides along its own wall only, never onto another wall. → Task 4 `slideAlongWall` test.
3. Ctrl+V of a host door with no wall within 1 m: nothing is pasted and a message says why. → Task 4 `pasteHost` test.
4. Undo right after a host move with streaming on: the element (and its joined walls) go back exactly. → Task 5 `MoveRevertTests`, Task 8 live step.
5. Ctrl+C / Ctrl+V while typing in a text field (search, settings) does not copy or paste elements. → Task 7 `isClipboardKey` test.
