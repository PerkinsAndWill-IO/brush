# KRO test drawings

Exported from a Perkins&Will project model (KRO, Revit 2026) for testing the viewer and the editor on a large real
project. Project data, not covered by the repository licence.

| File | Pages |
|---|---|
| `kro-test.drawing` | KRO-APD-ARC-PLN-A1A-N01-0001 (plan), KRO-APD-ARC-ELE-A1A-TTN-0032 (elevation), KRO-APD-ARC-SYN-A1A-TTN-0061 (synthesis) |

Stored with Git LFS: run `git lfs pull` after cloning. Open in the viewer with `?file=/examples/kro/kro-test.drawing`.

Known gaps of this export: the axonometric viewports on 0061 are not clipped and are drawn too large, some floor bands
on 0032 are filled solid black, and room tags on 0001 overlap.
